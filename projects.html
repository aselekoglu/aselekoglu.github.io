Career AI Platform

ApplAI

Personal Project · March 2026

Problem

Tailoring CVs and cover letters for individual job descriptions is highly repetitive, slow (often taking 2+ hours per role manually), and prone to copy-paste errors or misalignment.

Approach

  • Developed a private AI Career Manager utilizing Python/FastAPI backend services and Pydantic contracts for structured data validation.
  • Constructed a suggestions-first tailoring workflow that extracts structural metadata and requirements from incoming job descriptions.
  • Designed grounding mechanisms with provenance metadata, unsupported-claim checks, and ATS/QA reporting to prevent LLM hallucinations.
  • Created a React + TypeScript + Vite web interface where the user can review and edit suggested bullet points side-by-side with the original CV.
  • Implemented template-aware document rendering using python-docx and pdfplumber to export clean files matching specific page budgets.
  • Separated the agent orchestration layer (Eve) from deterministic Core services, keeping human-in-the-loop approval gates explicit.

Outcome

Reduces a 2+ hour manual resume tailoring process to minutes, ensuring strong alignment with job descriptions while guaranteeing factual accuracy and preserving final user control.

RAG Assistant

OPS Copilot (OPS Policy Chatbot)

Pilot Scaffold · 2026

Problem

Querying internal corporate policy, public-policy, and procedure documents (often hundreds of pages across PDF/DOCX) is slow for operational teams and prone to misinterpretation or hallucination if standard LLMs are used.

Approach

  • Engineered a Retrieval-Augmented Generation (RAG) pipeline with a FastAPI backend and a React/TypeScript/Vite frontend using Entra sign-in.
  • Built an ingestion pipeline featuring SHA-256 file deduplication, PDF/DOC/TXT parsing, and Azure Document Intelligence OCR fallback for low-confidence or scanned text.
  • Implemented top-k document retrieval using local embeddings and a FAISS vector database.
  • Set a strict minimum-similarity score gate to decline answering when no relevant source document is found, enforcing "cite-or-decline" behavior.
  • Integrated local Ollama models via LangChain components to process queries securely and locally without external cloud dependencies.

Outcome

A secure, pilot-ready ops chatbot that delivers reliable answers with exact file-path and page-number citations, reducing information discovery time while eliminating hallucination risk.

Computer Vision / MIDI tool

Air Controller

Creative Project · 2026

Problem

Live musical performances require expressive, continuous control over synthesizers and effects, but traditional MIDI controllers (knobs, faders) force musicians to take their hands off their instruments or occupy a fixed position on stage, limiting physical expression.

Approach

  • Developed a macOS-focused webcam-to-MIDI controller that runs locally in real-time, mapping hand movements to standard MIDI Control Change (CC) messages.
  • Implemented OpenCV for webcam frame capture and MediaPipe Hands for high-fidelity hand landmark tracking.
  • Built custom gesture smoothing, relative/absolute coordinate mapping, gesture hysteresis, and neutral-pose calibration to prevent sudden parameter jumps.
  • Configured CoreMIDI virtual port generation to route CC streams directly to DAWs like Logic Pro with low latency.
  • Added performance telemetry including rolling p50/p95 latency metrics, FPS overlays, and YAML-based per-instrument configuration files.

Outcome

Creates a highly expressive, touch-free gesture controller for live performance, enabling hands-free modulation of synth parameters with visual feedback and under 15ms of processing latency.
